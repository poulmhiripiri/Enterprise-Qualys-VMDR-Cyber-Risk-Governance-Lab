## GitHub Repository and Large File Guidance

- GitHub recommends using a README to explain what the project does, why it is useful and how reviewers should use it: https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-readmes
- GitHub blocks files larger than 100 MiB and recommends Git LFS for large files: https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github
- Git LFS stores large file references in the repository while keeping the actual large content separately: https://docs.github.com/repositories/working-with-files/managing-large-files/about-git-large-file-storage
