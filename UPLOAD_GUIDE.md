## Upload Steps

1. Create a new GitHub repository called `enterprise-qualys-vmdr-grc-lab`.
2. Choose **Public** if you want recruiters to view it.
3. Do not initialise with a README if uploading this full pack.
4. Upload the folders and files from this ZIP.
5. Add redacted screenshots into the relevant screenshot folders.
6. Add redacted PDF/CSV reports into the `reports` folder.
7. Confirm that no private data is visible before publishing.

## Important Redaction Checklist

Before uploading evidence, remove or blur:

- Personal names and addresses
- Email addresses
- Public IP addresses
- Internal IP addresses if sensitive
- Activation keys
- Subscription IDs
- Serial numbers
- Host IDs
- Account IDs
- Password fields
- Browser tabs containing private information
- Any customer or personal data


## Large File Note

This repository includes a full PDF evidence pack of approximately 62 MB. Because it is a large binary file, the most reliable upload method is GitHub Desktop or command-line Git rather than dragging many files into the browser. GitHub enforces a 100 MB single-file limit for normal Git repositories, so the included PDF should remain under that limit.

Suggested approach:

1. Create a new GitHub repository.
2. Open GitHub Desktop.
3. Clone the new empty repository to your PC.
4. Copy all extracted project folders and files into the cloned repository folder.
5. Commit with a message such as: `Initial Qualys VMDR GRC project upload`.
6. Push to GitHub.
