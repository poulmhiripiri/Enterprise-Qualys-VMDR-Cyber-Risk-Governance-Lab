# LinkedIn Project Description

I built an enterprise-style Qualys VMDR and CyberSecurity Asset Management lab to demonstrate how vulnerability management should operate as a governed cyber risk programme rather than a standalone scanning activity.

The project covered asset inventory, Windows/Linux endpoint onboarding, Qualys Cloud Agent deployment, vulnerability dashboards, open-port exposure review, software lifecycle and EOL visibility, scheduled scanning, patch deployment, certificate governance and executive reporting.

The key focus was translating technical findings into GRC outcomes: asset ownership, risk prioritisation, remediation tracking, patch assurance, exception management and management-level reporting.

This project strengthens my positioning across vulnerability management, infrastructure security, GRC, cloud security and security operations roles.
