# Video Evidence - Qualys Colleague Support Walkthrough

This folder contains a video walkthrough showing practical support provided to colleagues during Qualys setup and implementation.

## Included File

- `qualys-colleague-setup-and-implementation-walkthrough.mp4`
- `qualys-colleague-walkthrough-thumbnail.jpg`

## How to Use This Evidence

This video is useful as optional supporting evidence because it demonstrates communication, mentoring and practical implementation support. It can strengthen the project by showing that the work was not only theoretical or isolated lab activity, but also involved explaining and supporting Qualys setup for others.

## Recommendation

For GitHub, the video is optional because video files increase repository size. A better public-portfolio approach is usually to keep the video in one of these places and link to it from the README:

- LinkedIn featured section
- YouTube unlisted video
- Google Drive portfolio folder
- GitHub Release asset

If the video is kept inside the repository, use Git command line or Git LFS rather than browser upload, because large media files can fail in browser-based uploads.
