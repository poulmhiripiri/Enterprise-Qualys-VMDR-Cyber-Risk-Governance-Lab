# Patch Governance Process

## Objective

Patch governance ensures that missing patches are reviewed, prioritised, deployed, validated and reported in a controlled manner.

## Patch Process

1. Review missing patches
2. Assess severity and affected assets
3. Prioritise critical and high-risk patches
4. Confirm maintenance window
5. Create patch deployment job
6. Deploy patch
7. Monitor installation status
8. Reboot where required
9. Validate successful remediation
10. Report patch compliance status

## Patch Risk Controls

- Patch testing where possible
- Rollback planning
- Business owner communication
- Change approval for production systems
- Reboot coordination
- Failed patch investigation
- Exception approval where patching is delayed
