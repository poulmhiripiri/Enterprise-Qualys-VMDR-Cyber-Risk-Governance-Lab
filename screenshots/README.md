# Screenshot Evidence

This folder contains key screenshots extracted from the full Qualys evidence PDF and organised by implementation stage.

## Folder Structure

- `01-agent-onboarding` - Qualys agent download, activation and installation evidence
- `02-asset-inventory` - asset identity, system data, software inventory, lifecycle/EOL and open-port exposure
- `03-vulnerability-dashboard` - vulnerability dashboard, scheduled scans, filters and example findings
- `04-patch-management` - patch selection, patch jobs, installed patches and reboot evidence
- `05-executive-reports` - executive reporting, technology debt reporting and certificate evidence

For the full mapping, see `../evidence-index.md`.
