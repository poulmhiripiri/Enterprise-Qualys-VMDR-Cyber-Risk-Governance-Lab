# Asset Inventory Governance

## Objective

The objective of asset inventory governance is to ensure that all assets are discovered, classified, monitored and assigned appropriate ownership.

## Asset Data Captured

- Hostname
- Operating system
- Hardware details
- IP address
- Installed software
- Open ports
- Agent status
- Last check-in time
- Asset tags
- Location context

## GRC Importance

Asset visibility is the foundation of vulnerability management. If an organisation cannot identify its assets, it cannot reliably assess vulnerabilities, apply patches, manage certificates or report cyber risk.

## Governance Controls

| Control | Description |
|---|---|
| Asset Discovery | Qualys agents and sensors identify assets across the environment |
| Asset Classification | Assets are grouped by platform, business function, criticality and owner |
| Asset Ownership | Each asset or asset group should have an accountable owner |
| Lifecycle Tracking | Assets should be tracked from onboarding to decommissioning |
| Reporting | Asset inventory reports should support audit and executive reporting |
