# Software Lifecycle and End-of-Life Tracking

## Objective

Software lifecycle tracking helps identify unsupported, stale or end-of-life software that may increase operational and security risk.

## GRC Value

End-of-life software can create technology debt, compliance exposure and increased vulnerability risk. Tracking software lifecycle status allows IT and security teams to plan upgrades before risk becomes urgent.

## Review Criteria

- End-of-life software
- End-of-support software
- Unsupported versions
- High-risk applications
- Commercial vs open-source software
- Software publisher visibility
- Business owner assignment

## Governance Actions

1. Identify EOL/EOS software
2. Confirm business ownership
3. Assess vulnerability exposure
4. Plan upgrade, removal or replacement
5. Track exceptions where upgrade is delayed
6. Report technology debt to IT leadership
